# Power BI Sales Dashboard
This project analyzes retail sales data using Power BI to uncover business insights and performance trends.

## Project Overview
The dashboard provides insights into sales performance, product profitability, and regional distribution.

## Key Features
- Sales by Category analysis
- Profit by Sub-Category insights
- Monthly Sales Trend visualization
- Regional Sales comparison
- Top 10 Products analysis
- Customer Segment distribution

## Tools Used
- Power BI
- DAX
- Power Query
- Data Visualization
